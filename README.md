## 🌟 Key Features

- **Real-Time Transaction Analysis**: Analyzes payment streams in real time, detecting anomalies and flagging high-risk behavior before settlement.
- **Payment Gateway Integration**: Direct integration with the **Razorpay API** for live webhooks, transaction payload ingestion, and secure signature verification.
- **Machine Learning Risk Scoring**: Applied predictive ML models to generate instant numerical fraud-risk scores (0–100) and actionable decision flags.
- **Automated Security Guardrails**: Multi-layered security checks including velocity limits, IP geolocation mismatches, and behavioral deviations.
